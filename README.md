# Best Headliners Plus — multipage site

Incluye el homepage y cuatro subpáginas conectadas: `about.html`, `services.html`, `gallery.html` y `contact.html`. Todas comparten la paleta rojo/blanco/azul, la navegación responsive y las animaciones de aparición al hacer scroll. El hero fue reconstruido con HTML/CSS sobre una fotografía nueva de taller automotriz: no usa una captura como fondo. El bloque `.hero` ocupa `100svh` y `100vw`, con recorte responsive.

Los encabezados de las cuatro subpáginas se adaptan a la altura del título para no quedar debajo del menú. La selección de marcas forma parte de la fotografía original de alta resolución (`taller-workshop.png`) en escritorio y móvil; se muestra sin degradados oscuros, filtros ni capas de sombra. Las comparaciones antes/después en Services, Gallery y Home usan fotografías reales de Andy. Los textos de fecha impresos en algunas fotos se ocultan mediante el encuadre CSS de las tarjetas.

Abre `index.html` desde esta carpeta para mantener las rutas `css/`, `js/` y `assets/images/`. Para Vercel, sube la carpeta completa o el ZIP sin cambiar la estructura interna.
